# Changelog — Project LUX

### Added
- Canonical Neutral Eye (Asymmetrical leaf profile).
- 7-Phase Hardware Startup Sequence.
- Horizontal Visor Raster Layer.

- Refactored AutonomousEngine into decoupled layers: Perception, Attention, Planning, Animation.
- Unified rendering pipeline under EyePathBuilder.
- Cleaned up logic duplication and legacy artifacts.
