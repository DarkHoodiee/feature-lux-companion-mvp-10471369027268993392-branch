# Contributing to LUX Hoodie

## Branching Model
- `main`: Stable production-ready code.
- `develop`: Active integration branch.
- `feature/*`: New capabilities or refactors.

## Coding Standards
- Follow Kotlin coding conventions.
- Use Jetpack Compose for all UI and rendering.
- Maintain the 7-layer cognitive hierarchy.
- Comments should explain **WHY**, never **WHAT**.

## Change Guidelines
- One roadmap task per pull request.
- Verify visual output before submitting.
- Do not introduce per-frame allocations in the renderer.
